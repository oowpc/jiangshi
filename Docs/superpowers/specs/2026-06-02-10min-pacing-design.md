# 前 10 分钟游戏节奏设计

> 状态：已确认  
> 日期：2026-06-02

## 一、设计原则

基于四个设计选择：

| 维度 | 选择 | 说明 |
|------|------|------|
| 情绪基调 | 高压生存 | 每时每刻都在挣扎，建错即崩 |
| 波次结构 | 少量大波（4波） | 间隔90~150s，每波都是一次生死考验 |
| 开局经济 | 紧巴（200金+50木+30电） | 够2~3个建筑，必须规划 |
| 敌人种类 | 经典三件套 | 普通→高速→大型，逐波解锁新类型 |

---

## 二、10 分钟时间线

```
0:00 ─────────── 2:00 ──── 4:00 ────── 6:30 ──── 8:30 ── 10:00
  准备阶段       第一波    战备       第二波    战备     第三波     战备    第四波    胜利
  2分钟          30s       90s       30s       120s      30s       90s       30s       90s
```

### 各阶段详述

#### 0:00 - 2:00 准备阶段
- 起始资源：**200 金 / 50 木 / 30 电力**（食物、铁、铜为 0）
- 0:00 时指挥基地已存在于地图中央
- 玩家需要立即做出开局方向选择：
  - **防御优先**：1 箭塔（80金+30木+2电）+ 1 城墙（10金+5木） → 剩余 110金+15木+28电
  - **经济优先**：1 金矿（40金+40木+2食物）+ 1 箭塔（80金+30木+2电） → 剩余 80金-20木（可能不够，需要取舍）
  - **混合路线**：1 伐木场（40金+10木+2电）+ 1 箭塔（80金+30木+2电） → 剩余 80金+10木+26电
- 无敌人出现，是仅有的安全窗口
- UI 显示倒计时：「第一波 2:00 后到来」

#### 2:00 第一波 · 初次试探
- **20 只普通丧尸**，从 1~2 个地图边缘方向生成
- 难度：★★（入门级压力，验证基础防御）
- 丧尸属性：35 HP / 2 移速 / 6 伤害 / 1.2 范围
- 预期玩家状态：至少 1 座箭塔 + 1 段城墙

#### 2:30 - 4:00 战备期
- 第一波清除后，约 90 秒发展时间
- 建议动作：补充经济建筑（伐木场/金矿）、加固城墙
- UI 显示倒计时：「第二波 4:00 后到来」

#### 4:00 第二波 · 速度威胁
- **30 只丧尸**：21 普通 + **9 高速**
- 从 2 个方向生成
- 难度：★★★
- **高速丧尸属性**：30 HP / 4 移速 / 4 伤害 / 1.0 范围（快但脆）
- 高速丧尸会先于大部队冲线，考验火力密度和城墙覆盖率
- 预期玩家状态：1~2 座箭塔 + 城墙防线

#### 5:00 - 6:30 战备期
- 约 90 秒发展时间
- 建议动作：建造兵工厂开始训练弓箭手（50金+20木/10s），扩张箭塔数量
- UI 显示倒计时：「第三波 6:30 后到来」

#### 6:30 第三波 · 庞然大物
- **35 只丧尸**：15 普通 + 12 高速 + **8 大型**
- 从 2~3 个方向生成
- 难度：★★★★
- **大型丧尸属性**：120 HP / 1 移速 / 12 伤害 / 1.5 范围（血厚攻高）
- 大型丧尸3倍血量，可承受大量箭塔火力走到城墙前
- 第一次必须依赖弓箭手/士兵集中火力击杀
- 预期玩家状态：2~3 座箭塔 + 2~3 名弓箭手 + 城墙防线

#### 6:30 - 8:30 战备期
- 约 90 秒发展时间（长战备窗口，为最终波做准备）
- 建议动作：补满4座箭塔、继续训练单位、加固城墙
- UI 显示倒计时：「最终冲击 8:30 后到来」

#### 8:30 第四波 · 最终冲击
- **40 只丧尸**：10 普通 + 15 高速 + **15 大型**
- 从 **全部 4 个方向**同时生成
- 难度：★★★★★
- 四面楚歌，地图边缘全方向进攻，考验全方位防御
- 大型丧尸15只集中冲击，需要所有箭塔和单位协同火力
- 预期玩家状态：4 座箭塔 + 4~6 名弓箭手 + 完整城墙 + 1~2 名士兵

#### 10:00 胜利
- SurvivalTimer 到期，触发 Victory
- 显示统计：生存时间、击杀总数、剩余建筑数

## 四、敌人种类

### 普通丧尸（Normal Zombie）
- **UnitData 字段**：现有 ZombieData
- HP：35 | 移速：2 | 伤害：6 | 范围：1.2
- 首个波次（第1波）即成批登场
- 数量随波次递减（20→21→15→10），让位给更高阶敌人

### 高速丧尸（Fast Zombie）
- **新 UnitData**：FastZombieData（需新建 prefab + ScriptableObject）
- HP：30 | 移速：4 | 伤害：4 | 范围：1.0
- 第2波首次登场（9只）
- 比普通丧尸快100%，但血量更低、伤害更小
- 视觉区分：Sprite 稍小、移动更快、颜色偏红

### 大型丧尸（Large Zombie）
- **新 UnitData**：LargeZombieData（需新建 prefab + ScriptableObject）
- HP：120 | 移速：1 | 伤害：12 | 范围：1.5
- 第3波首次登场（8只）
- 3倍血量，充当肉盾角色，吸收箭塔火力
- 慢速但伤害高，走到城墙上会造成严重破坏
- 视觉区分：Sprite 放大1.5倍、颜色偏紫

## 五、经济设计

### 起始资源
| 资源 | 数量 | 用途 |
|------|------|------|
| 金 | 200 | 建筑和训练主要消耗 |
| 木 | 50 | 箭塔/城墙辅助消耗 |
| 电 | 30 | 建筑电力维护费 |
| 其他 | 0 | 食物/铁/铜初期不计入 |

### 关键数值（与现有 BuildingData 对齐）
- 箭塔成本：80金+30木+2电 → 起始可建 2 座（剩余40金）
- 城墙成本：10金+5木 → 几乎免费
- 金矿成本：40金+40木+2食物 → 起始可建但会消耗大量木头
- 伐木场成本：40金+10木+2电 → 起始可建
- 兵工厂成本：参考现有 BarracksData
- 训练弓箭手：50金+20木 / 10s训练

### 预期开局三路线
1. **防御流**：箭塔×2 + 城墙 → 剩余 40金+0木，经济起步慢但防御稳固
2. **经济流**：金矿 + 箭塔 → 木不够需要等伐木场，第二波前经济起飞
3. **均衡流**：伐木场 + 箭塔 → 木材自给自足，利于后续扩张

## 七、实现要点

### 需要新建的资产
1. **FastZombieData.asset** — 高速丧尸 UnitData
2. **LargeZombieData.asset** — 大型丧尸 UnitData
3. **FastZombie.prefab** — 高速丧尸 Prefab（Zombie prefab 变体，调色+调速）
4. **LargeZombie.prefab** — 大型丧尸 Prefab（Zombie prefab 变体，缩放+变色）
5. **Wave02.asset ~ Wave04.asset** — 替换现有的 Wave01，或新增 4 个 WaveData

### 需要修改的现有系统
1. **SurvivalTimer** — `durationSeconds` 从 180 改为 600
2. **WaveManager** — 支持每个波次指定不同 enemy（需确认是否已支持）
   - 现有 `WaveData.enemy` 是单个 UnitData，每波不同敌人类型需不同 WaveData
   - 已支持：`WaveManager` 按 `startTime` 排序，每波独立 enemy
3. **ResourceManager** — 起始资源需从当前默认值改为 200金+50木+30电
4. **PrototypeHud** — 波次状态文本中文化、增加波次编号显示

### WaveData 需要扩展的字段
当前 `WaveData` 只有一个 `enemy` 字段。4个波次中第2~4波需要多种敌人混合。有两条路径：

**方案A（推荐）**：扩展 `WaveData` 增加多个 enemy 字段
```csharp
// WaveData.cs 增加
public EnemyGroup[] enemyGroups;

[System.Serializable]
public struct EnemyGroup
{
    public UnitData enemy;
    public int count;
}
// 保留 count 字段作为总量
// enemyGroups 为空时回退到原来的 enemy + count 单一类型
```

**方案B**：每个 enemy 类型单独一个 WaveData
- 需要 4×3=12 个 WaveData（4波 × 最多3种敌人）
- 优点：最小改动，无需改 WaveData 结构
- 缺点：配置繁琐，语义不清

### 方向控制
当前 `WaveManager` 随机从所有 `spawnPoints` 中选一个。需要支持：
- 第1~2波：指定 spawn 方向数（1-2个）
- 第4波：从4个方向同时生成（"四面楚歌"）

建议：`WaveData` 增加 `int spawnDirections = 1` 字段，控制每波使用不同 spawnPoints 的数量。

## 八、不做（明确排除）

1. 特殊事件（黑夜、双路等）——用户选择经典三件套，无特殊事件
2. 自爆/呕吐者等新敌人类型——首版仅三件套
3. 起始资源可配置 UI —— 目前硬编码即可
4. 波次难度动态调整 —— 首版固定配置
